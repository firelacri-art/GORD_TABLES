# Стиль таблиц GORD Agency — спецификация

Источник: эталонная Google-таблица агентства «Novikov x Yoomoota» (11 листов проекта
мероприятия), разобранная по ячейкам, плюс визуальный стандарт GORD для презентаций
(палитра Signal Clay / Rich Black, шрифт Geologica). Все значения ниже — измеренные,
не «на глаз». Генератор `scripts/build_gord_table.py` воспроизводит их автоматически;
эта страница нужна, когда таблицу правят руками или собирают другим инструментом.

---

## 1. Обязательные элементы каждого листа

1. **Логотип GORD сверху слева** — PNG с прозрачным фоном (`assets/gord-logo.png`,
   1402×708 px: чёрное «GORD», красное рукописное «agency»). Якорь — колонка A,
   строка 1–2. На рабочих листах 838 200 × 419 100 EMU (≈ 88 × 44 px, 0,92″ × 0,46″),
   на дашборде и разборе проекта крупнее — 1 190 625 × 600 075 EMU (≈ 125 × 63 px).
   Логотип **не** растягивается по ширине таблицы и не центрируется: он всегда в
   левом верхнем углу, как штамп.
2. **Красный акцент `#D72410`** — ровно один на лист:
   - на листах-таблицах — линейка `medium` под строкой логотипа (нижняя граница
     строки 2 от первой до последней колонки таблицы);
   - на карточках (дашборд, разбор) — толстая (`thick`) красная рамка вокруг блока
     с названием проекта.
   Больше красного на листе быть не должно (кроме самого логотипа).
3. **Заголовок листа** — строка 3, объединена по ширине таблицы, Geologica 14 Bold,
   чёрный, слева, по вертикали по центру, высота строки 27 pt. Регистр — как в
   названии («План работы», «Гости мероприятия»); допускается ВЕРХНИЙ для сметы
   («СМЕТА МЕРОПРИЯТИЯ»).
4. **Шапка таблицы** — строка 4, заливка `#F3F3F3`, Geologica 10 Bold, по центру
   по обеим осям, перенос по словам, тонкие чёрные рамки, высота 33 pt.
5. **Шрифт Geologica везде.** Ни одной ячейки на Arial/Calibri/Roboto. Эталон
   исторически смешивал Geologica/Montserrat/Roboto — это ошибки ручной правки, в
   новых таблицах их не воспроизводим.

## 2. Сетка листа-таблицы

```
   A(2.29)  B(5.86)  C(60)   D(22)   E(32)   F(35)   G(22)   H(2.14)
1  ·        [пусто, 10 pt]
2  [лого]   ───────────────── красная линейка D72410 ─────────────────
3           План работы                                   (Geologica 14 B)
4           Задача            Дедлайн  Ответств. Коммент.  Статус     (F3F3F3)
5           1  Текст задачи   21.07    Gord      …         выполнено
6           2  …
```

- **Колонка A — поле 2,29** (пустая, узкая). Данные начинаются с B.
- **Колонка №** (если нумерация) — ширина 5,86, числа Geologica 9 Bold по центру.
  В шапке ячейка № объединяется с первой содержательной колонкой (B4:C4 = «Задача»).
- После последней колонки — **хвостовая колонка 2,14** (воздух справа).
- Ширины содержательных колонок (символы Excel): текстовая главная 60; дата/время
  22; ответственный 32; комментарии 35; статус 22–28; ссылка 28–40; числа 16–21.
- **Строки данных 15 pt**, перенос по словам включён, вертикаль — по центру.
- **Рамки:** заполненные строки — тонкие чёрные `#000000`; пустые строки-заготовки
  (задел под будущие записи) — тонкие светло-серые `#D9D9D9`. Пустых строк
  оставляем 12–20, чтобы менеджер вписывал руками без форматирования.
- **Зебра** (чередование `#F3F3F3` / белый) — только на «Плане подготовки»; на
  остальных листах строки белые.
- **Секции** внутри таблицы (СМИ / Блогеры; Telegram / Instagram) — строка, объединённая
  по ширине, Geologica 9 Bold по центру, под ней красная линейка `medium`.
- **Итоговая строка** («ИТОГО (с НДС)») — через одну пустую строку после данных,
  заливка `#D9D9D9`, Bold, формула `=SUM()` по числовым колонкам.

## 3. Сетка листа-карточки (дашборд / разбор проекта)

```
   A(1.71)  B(32)                     C(68)                          D(8)
1  [лого крупный, строка 52.5 pt]
2  ┌──────── толстая красная рамка D72410 ────────┐
   │ Novikov: аукцион Yoomoota   (Geologica 13 B) │   строка 105 pt (дашборд) / 52.5 (разбор)
   └──────────────────────────────────────────────┘
3  [пусто 18.75]
4  Дата мероприятия  (9 B)   │ 4 сентября 2026
5  PR-менеджер проекта       │ Кристина
6  Материалы                 │ https://…  (синяя ссылка)
```

- Подписи полей — Geologica 9 Bold, значения — Geologica 9 Regular, рамки тонкие
  тёмно-серые `#434343`.
- На «Разборе проекта» строки высокие (60 pt), выравнивание по верху — под
  многострочные ответы.

## 4. Палитра

| Роль | HEX | Где |
| --- | --- | --- |
| Signal Clay (акцент) | `#D72410` | линейка под логотипом, рамка названия, линии секций |
| Rich Black / текст | `#000000` | весь текст, рамки заполненных строк |
| Тёмно-серый | `#434343` | рамки карточек дашборда |
| Шапка / зебра | `#F3F3F3` | шапка таблицы, чередование строк плана |
| Итог / заготовки | `#D9D9D9` | строка ИТОГО, рамки пустых строк |
| Ссылка | `#1155CC` | гиперссылки, с подчёркиванием |
| Статус «готово» | фон `#D9EAD3`, текст `#274E13` | выполнено / оплачено / доставлено / готово |
| Статус «в работе» | фон `#FFF2CC`, текст `#7F6000` | в работе / в процессе / ожидаем |
| Статус «проблема» | фон `#F4CCCC`, текст `#990000` | не оплачено / не доставлено / отказ |
| Статус «не начато» | фон `#EFEFEF`, текст `#434343` | не в работе / не связались |

Бежевый `#CDB996`, золото `#B2875A` и чёрные фоны из презентационного стандарта в
таблицах **не используются** — таблица всегда белая, «воздушная».

## 6. Форматы данных

- Числа с разрядкой пробелом: формат `#\ ##0` → `316 272 358`, `2 769 000`.
- Даты: `[$-419]dd.mm.yyyy` → `21.07.2026`; в карточке `[$-419]d mmmm yyyy` →
  `4 сентября 2026`. В JSON даты пишутся ISO (`2026-09-04`), генератор конвертирует.
- Время: `hh:mm` → `19:30` (в JSON `"19:30"`).
- Ссылки — реальные гиперссылки (кликабельные), не голый текст.
- Статусы — выпадающий список (data validation) + условное форматирование по
  значению. Списки стандартные:
  - работа: `не в работе · в работе · выполнено`
  - готовность: `Не в работе · В работе · Готово`
  - оплата: `Не оплачено · Оплачено · Оплачено 3-м лицом, возместить оплату`
  - доставка: `Не доставлено · В процессе доставки · Доставлено`

## 7. Лист и печать

- Имена листов — русские, короткие, как в эталоне: «Дашборд проекта», «Смета»,
  «План подготовки», «Контакты», «Логистика», «Тайминг», «Чек-лист неделя»,
  «Чек-лист за 3 дня», «Чек-лист после ивента», «Гости», «Разбор проекта».
- Порядок листов: дашборд → деньги → план → справочники → чек-листы → гости → разбор.
- Сетка Excel остаётся видимой (как в эталоне); скрыть — опция `hide_gridlines`.
- Печать: альбомная, вписать по ширине в 1 страницу, поля 0,4–0,5″.
- Закрепление шапки и автофильтр — по запросу (`freeze`, `autofilter`), по умолчанию нет.

## 8. Чек-лист перед отправкой клиенту

- [ ] Логотип в левом верхнем углу **каждого** листа, не растянут, не обрезан.
- [ ] Красная линейка под логотипом (таблицы) / красная рамка названия (карточки).
- [ ] Все ячейки — Geologica; ни одной на Arial/Calibri.
- [ ] Шапка `#F3F3F3`, жирная, по центру, с переносом.
- [ ] Числа с разрядкой пробелом, даты `дд.мм.гггг`.
- [ ] Статусы — выпадающие списки, подсвечиваются цветом.
- [ ] Есть пустые строки-заготовки (12–20) с серыми рамками.
- [ ] Один красный на лист. Никаких синих заливок, «умных таблиц» Excel, градиентов.
- [ ] Название проекта в формате `Клиент: событие` или `GORD AGENCY x BRAND`.
