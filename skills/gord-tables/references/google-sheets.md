# Google Таблицы: как получить GORD-таблицу в Google Sheets

Генератор делает `.xlsx`. Google Таблицы импортируют его **без потерь стиля**:
логотип (картинка над ячейками), шрифт Geologica (есть в Google Fonts, поэтому
рендерится у любого пользователя без установки), заливки, рамки, объединения,
ширины колонок, выпадающие списки статусов и условное форматирование переносятся.
Поэтому основной путь — собрать xlsx и превратить его в Google-таблицу.

## Путь 1 — импорт файла (2 минуты, без API)

1. Открыть [sheets.new](https://sheets.new) или Google Drive → «Создать» → «Google Таблицы».
2. Файл → **Импортировать** → «Загрузка» → выбрать `.xlsx`.
3. Место импорта: **«Заменить таблицу»** (для новой) или «Вставить новые листы»
   (добавить в существующую). Нажать «Импортировать данные».
4. Проверить: логотип на каждом листе, шрифт в панели инструментов показывает
   `Geologica`, статусы окрашены. Переименовать файл по шаблону
   `Клиент x Проект` (как «Novikov x Yoomoota»).
5. Настроить доступ (обычно «Все, у кого есть ссылка — Редактор» для команды клиента).

Альтернатива: загрузить xlsx на Drive → ПКМ → «Открыть с помощью → Google Таблицы»
→ Файл → «Сохранить как Google Таблицу». Результат тот же.

## Путь 2 — обновить уже существующую Google-таблицу клиента

Если у клиента есть живая таблица и нужно добавить лист в стиле GORD:
1. Собрать xlsx только с нужными листами.
2. В таблице клиента: Файл → Импортировать → «Вставить новые листы».
3. Перетащить вкладку на нужное место. Существующие листы не затрагиваются.

## Путь 3 — через браузер агентом (Chrome MCP / Browser pane)

Если в сессии есть инструменты браузера с авторизованным Google-аккаунтом,
агент может пройти путь 1 сам: открыть `https://sheets.new`, Файл → Импортировать,
загрузить файл через `file_upload`, выбрать «Заменить таблицу», дождаться импорта,
переименовать и вернуть пользователю ссылку. Загрузка файла и выдача доступа —
действия с побочными эффектами: подтверждать у пользователя перед выполнением.

## Путь 4 — Google Sheets API (когда нужна автоматизация)

Если у пользователя настроен доступ к API (сервис-аккаунт или OAuth, библиотеки
`gspread` / `google-api-python-client`):
- самый надёжный способ — загрузить xlsx на Drive с конвертацией
  (`files.create` с `mimeType: application/vnd.google-apps.spreadsheet`), так
  форматирование переносится целиком, включая картинку логотипа;
- прямое создание через `spreadsheets.batchUpdate` возможно, но тогда логотип
  придётся вставлять отдельно (`=IMAGE("https://…/gord-logo.png")` в ячейке A1
  с высотой строки 50 или картинкой над ячейками через UI), а стили задавать
  вручную по `references/gord-table-style.md`. Выбирать этот путь только если
  xlsx-импорт по какой-то причине не подходит.

## Что проверить после импорта

- [ ] Логотип виден на каждом листе и не перекрывает заголовок.
- [ ] Шрифт ячеек — Geologica (клик в ячейку → в панели инструментов «Geologica»).
- [ ] Красная линейка под логотипом / красная рамка названия на месте.
- [ ] Выпадающие списки статусов работают, цвет меняется при выборе.
- [ ] Ссылки кликабельны.
- [ ] Числа с разрядкой пробелом, даты `дд.мм.гггг`.

## Известные отличия Excel ↔ Google Sheets

- Google показывает статусы как обычные ячейки с условным форматированием, а не
  как «чипы» нового интерфейса. Если клиент хочет чипы: Данные → Проверка данных →
  «Раскрывающийся список» → включить «Показывать как чип» — значения и цвета
  подхватятся из существующего списка.
- Высота строк в Google может оказаться чуть больше из-за метрик шрифта — это норма.
- Формат даты `[$-419]…` Google понимает как русский; если Google показывает
  английские месяцы — Файл → Настройки → Язык «Россия».
