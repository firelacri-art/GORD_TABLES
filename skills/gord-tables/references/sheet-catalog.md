# Каталог листов и формат JSON-спецификации

Генератор собирает книгу из списка листов. Каждый лист — либо `preset` (типовой лист
агентства с готовыми колонками), либо произвольная таблица с собственными `columns`.
Проверить актуальный список пресетов: `python3 scripts/build_gord_table.py --presets`.

## Формат спецификации

```json
{
  "project": "Клиент: событие",           // название проекта — в заголовок дашборда и свойства файла
  "logo": "optional/path/logo.png",       // необязательно; по умолчанию assets/gord-logo.png
  "sheets": [
    { "preset": "dashboard", "values": { "Дата мероприятия": "2026-09-04", "PR-менеджер проекта": "Кристина" } },
    { "preset": "plan", "rows": [ { "Задача": "…", "Дедлайн": "2026-07-21", "Ответственный": "Gord Agency", "Статус": "выполнено" } ] },
    { "preset": "checklist", "name": "Чек-лист неделя", "title": "Чек-лист за неделю до ивента" },
    {
      "kind": "table", "name": "Своя таблица", "title": "Заголовок листа",
      "numbered": true, "zebra": false, "min_rows": 15, "freeze": false, "autofilter": false,
      "columns": [
        { "header": "Название", "width": 40, "bold": true },
        { "header": "Дата", "width": 20, "align": "center", "format": "[$-419]dd.mm.yyyy" },
        { "header": "Сумма", "width": 18, "align": "center", "format": "#\\ ##0" },
        { "header": "Ссылка", "width": 30, "link": true },
        { "header": "Статус", "width": 24, "status": ["Не начато", "В работе", "Готово"] }
      ],
      "rows": [ { "Название": "…", "Дата": "2026-09-10", "Сумма": 15000, "Ссылка": "https://…", "Статус": "В работе" } ],
      "total": { "label": "ИТОГО", "sum_columns": ["Сумма"] },
      "sections": ["Секция 1", "Секция 2"]
    }
  ]
}
```

### Поля листа

| Поле | Значение |
| --- | --- |
| `preset` | имя пресета (ниже). Все остальные поля переопределяют пресет |
| `kind` | `table` (по умолчанию) или `card` (карточка «подпись — значение») |
| `name` | имя вкладки (≤ 31 символ) |
| `title` | заголовок листа в строке 3; по умолчанию = `name` |
| `columns` | список колонок: `header`, `width`, `align` (`left`/`center`/`right`), `bold`, `wrap`, `format`, `link`, `status` (список значений) |
| `extra_columns` | добавить колонки к пресетным, не заменяя их |
| `rows` | список объектов «заголовок колонки → значение». Для листов с `sections` — словарь `{секция: [строки]}` либо список с полем `section` |
| `numbered` | колонка № слева (по умолчанию как в пресете) |
| `zebra` | чередование строк `#F3F3F3` |
| `min_rows` | минимум строк (недостающие — пустые заготовки с серыми рамками) |
| `sections` | секции-разделители внутри таблицы |
| `total` | итоговая строка: `label`, `sum_columns` |
| `freeze` / `autofilter` / `hide_gridlines` | закрепить шапку / автофильтр / скрыть сетку |
| `fields` / `values` | для `card`: список подписей и словарь значений |
| `tall_rows` | для `card`: высокие строки под развёрнутые ответы |

Значения: даты — ISO `2026-09-04` или `2026-09-04 19:30`, время — `19:30`, числа —
числа (не строки), ссылки — с `http`. Всё остальное — текст как есть.

## Пресеты (структура эталонной таблицы агентства)

### Проект мероприятия (11 листов эталона)

| preset | Вкладка | Колонки / поля | Особенности |
| --- | --- | --- | --- |
| `dashboard` | Дашборд проекта | Дата мероприятия · PR-менеджер проекта · Клиент · Площадка · Материалы | карточка, крупный логотип, название проекта в красной рамке |
| `budget` | Смета | Позиция · Кол-во / часы · Стоимость RUB с налогом · Стоимость RUB · Комментарий · Статус оплаты | без нумерации, ИТОГО (с НДС) = SUM, статусы оплаты |
| `plan` | План подготовки | № · Задача · Дедлайн · Ответственный · Комментарии · Статус | зебра, задача жирным, статусы `не в работе / в работе / выполнено` |
| `contacts` | Контакты | № · Подрядчик / партнер · Контакт · Ответственный · Комментарии | |
| `logistics` | Логистика | № · Что доставляем · Контакт · Откуда · Куда · Дата и время · Статус | статусы доставки |
| `timing` | Тайминг | № · Действие · Время · Ответственный · Статус | время `hh:mm`; в `title` подставляй дату: «Тайминг аукциона 4 сентября» |
| `checklist` | Чек-лист | № · Действие · Ответственный · Статус | используется дважды: «Чек-лист неделя», «Чек-лист за 3 дня» — задавай `name` и `title` |
| `checklist-after` | Чек-лист после ивента | № · Действие · Ответственный · Дедлайн · Статус | |
| `guests` | Гости | Название · Ссылка · Кол-во подписчиков · Ниша · Комментарии · Кто зовет | секции СМИ / Блогеры / Партнеры / VIP-гости |
| `debrief` | Разбор проекта | Что прошло хорошо · Какие были проблемы · Что можно улучшить · Количество гостей · Общий охват · Количество публикаций | карточка с высокими строками |

### PR-сопровождение и отчётность

| preset | Вкладка | Колонки | Особенности |
| --- | --- | --- | --- |
| `publications` | Публикации | № · Площадка · Дата · Ссылка · Охват · PR Value, ₽ · Комментарий | ИТОГО по охвату и PR Value — цифры для слайда «Результаты» |
| `media-list` | Медиалист | № · СМИ / площадка · Рубрика / формат · Контакт · Охват · Статус · Ссылка на публикацию | статусы `Не связались / Отправлен релиз / Публикация вышла / Отказ` |
| `bloggers` | Список блогеров | Имя · Ссылка · Кол-во подписчиков · Род деятельности · Статус | секции Telegram / Instagram (как на слайде 9 отчёта) |
| `roadmap` | Road map | Блок работ · Описание · Опорные даты · Ответственный · Сроки | структура слайда 8 отчёта; секции «БЛОК РАБОТ» / «ПОДГОТОВКА МЕНЮ» задаются через `sections` |

## Типовые наборы

- **Проект мероприятия** (аукцион, ужин, презентация, открытие): dashboard, budget,
  plan, contacts, logistics, timing, checklist ×2, checklist-after, guests, debrief.
  Готовый пример: `scripts/examples/event-project.json`.
- **Месячный отчёт по PR-сопровождению**: dashboard («Итоги месяца»), publications,
  media-list, bloggers, roadmap. Пример: `scripts/examples/monthly-report.json`.
- **Одна таблица** (клиент просит «просто план» / «просто список»): один лист нужного
  пресета. Пример: `scripts/examples/simple-plan.json`.
