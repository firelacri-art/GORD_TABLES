# Таблицы в стиле GORD (Excel + Google Sheets)

Стандарт агентства: **любая таблица, уходящая клиенту, выглядит одинаково** — логотип
GORD в левом верхнем углу каждого листа, шрифт Geologica, одна красная линейка
`#D72410`, серая шапка `#F3F3F3`, статусы выпадающим списком с цветом. Не изобретай
оформление заново: собирай генератором и правь только содержание.

## Быстрый путь

1. **Собери содержание** из запроса: название проекта («Клиент: событие»), какие
   листы нужны (см. пресеты), строки данных, если они есть. Что не сказано — не
   выдумывай: оставляй пустые строки-заготовки, они предусмотрены (`min_rows`).
2. **Напиши JSON-спецификацию** (формат — [references/sheet-catalog.md](references/sheet-catalog.md);
   готовые примеры — `scripts/examples/*.json`). Даты — ISO `2026-09-04`, числа — числами,
   ссылки — с `http`.
3. **Собери файл:**
   ```bash
   pip install -q openpyxl Pillow        # один раз
   python3 ${CLAUDE_SKILL_DIR}/scripts/build_gord_table.py spec.json "Клиент x Проект.xlsx"
   ```
   Посмотреть пресеты: `python3 ${CLAUDE_SKILL_DIR}/scripts/build_gord_table.py --presets`.
   Собрать эталонный проект мероприятия из 11 листов целиком:
   `python3 ${CLAUDE_SKILL_DIR}/scripts/build_gord_table.py --example event-project out.xlsx`.
4. **Проверь:**
   ```bash
   python3 ${CLAUDE_SKILL_DIR}/scripts/verify_gord_table.py "Клиент x Проект.xlsx" --render
   ```
   Скрипт проверяет логотип, шрифт, шапку и красный акцент на каждом листе; с
   `--render` кладёт PNG страниц (нужен LibreOffice) — открой их и посмотри глазами:
   ничего не обрезано, заголовки не налезают на логотип, статусы окрашены.
5. **Отдай результат.** Если нужна Google-таблица — следуй
   [references/google-sheets.md](references/google-sheets.md): xlsx импортируется в
   Google Sheets без потерь (логотип, Geologica, списки, подсветка переносятся).

## Какие листы выбирать

| Запрос | Листы (пресеты) |
| --- | --- |
| «таблица проекта / мероприятия», «как у нас по Novikov» | `dashboard, budget, plan, contacts, logistics, timing, checklist ×2, checklist-after, guests, debrief` — пример `examples/event-project.json` |
| «смета» | `budget` (+ `dashboard`, если это отдельный файл) |
| «план работ / подготовки», «дорожная карта по задачам» | `plan` |
| «чек-лист» | `checklist` (задай `name`/`title`: «за неделю», «за 3 дня») или `checklist-after` |
| «тайминг» | `timing` — дату события в `title` |
| «гости», «список приглашённых» | `guests` с секциями СМИ / Блогеры / Партнеры |
| «список блогеров» (слайд 9 отчёта) | `bloggers` с секциями Telegram / Instagram |
| «медиалист», «база СМИ» | `media-list` |
| «road map» (слайд 8 отчёта) | `roadmap` |
| «публикации за месяц», «AVE/OTS», «охваты» | `publications` — итоги идут в презентацию-отчёт |
| «разбор / ретро проекта» | `debrief` |
| что-то нестандартное | `kind: table` со своими `columns` — стиль подтянется автоматически |

Имя вкладки и заголовок листа задавай по-русски, как в эталоне. Один файл — один
проект; название файла и `project` — `Клиент x Проект` / `Клиент: событие`.

## Правила, которые нельзя нарушать

- **Логотип — на каждом листе**, только стандартный `assets/gord-logo.png`, слева
  сверху, не растянут. Свой логотип клиента в шапку не ставим (это документ агентства).
- **Только Geologica.** Никаких Arial/Calibri/Roboto, даже в одной ячейке.
- **Один красный на лист** — линейка под логотипом или рамка названия. Синих и
  цветных заливок, «умных таблиц» Excel, градиентов, иконок — нет.
- **Числа с разрядкой пробелом** (`316 272 358`), даты `дд.мм.гггг`, время `чч:мм`.
- **Статусы — списком**, не свободным текстом. Стандартные наборы — в пресетах.
- **Пустые строки-заготовки оставляем** (12–20): менеджер дописывает руками и не
  должен форматировать.
- Не смешивай стили эталона и презентаций: бежевый/чёрный фон, вертикальный
  вотермарк — это для слайдов, не для таблиц.

## Переделать чужую таблицу в стиль GORD

1. Прочитай исходник (`openpyxl` или экспорт Google-таблицы через
   `https://docs.google.com/spreadsheets/d/<ID>/export?format=xlsx`).
2. Перенеси **данные** в JSON-спецификацию: колонки → `columns`, строки → `rows`,
   подходящий пресет — если структура совпадает.
3. Собери генератором. Ручное «докрашивание» старого файла — только если клиент
   явно просит сохранить его структуру; тогда сверяйся с
   [references/gord-table-style.md](references/gord-table-style.md) по каждому элементу.

## Если Geologica не установлена в Excel

Файл всё равно корректный: имя шрифта записано, Excel подставит замену до установки.
Для точного вида поставить `assets/fonts/Geologica-VariableFont.ttf` (macOS — двойной
клик → «Установить»; Linux — `~/.local/share/fonts` + `fc-cache -f`; Windows — ПКМ →
«Установить»). Google Таблицы показывают Geologica без установки.
